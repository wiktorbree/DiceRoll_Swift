# 🎲 DiceRoll

A very simple iOS app built with SwiftUI that lets you roll a dice with the tap of a button.

## 📱 Preview

<img src="[/images/output/video1.gif](https://github.com/user-attachments/assets/3e4f3b8c-ea78-4501-ad0b-096f0c270ec7)" width="250" height="250"/>


## ✨ Features

- Tap a button to roll a 6-sided dice
- Displays the current dice face using an image
- Smooth UI using SwiftUI
- Simple and clean design

## 🛠️ Technologies

- Swift
- SwiftUI

## 📦 Project Structure

- `ContentView.swift`: Main UI and logic
- Dice face images should be named `1.png`, `2.png`, ..., `6.png` and added to Assets.xcassets
